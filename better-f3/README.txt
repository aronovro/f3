Better F3 (Freecam) — Fabric, Minecraft 1.21.11

Сборка:  gradle build   (или ./gradlew build, если добавишь gradle wrapper)
Результат: build/libs/better-f3-1.0.0.jar -> в папку mods

Управление: клавиша "turn f3 on/off" (по умолчанию F6, меняется в
Настройки -> Управление -> Better F3).
WASD / Space / Shift — полёт, Ctrl — ускорение, мышь — поворот.

Если версии в gradle.properties не сходятся — возьми актуальные на https://fabricmc.net/develop

Без установки Gradle: залей папку на GitHub (репозиторий) -> вкладка Actions ->
build -> Artifacts -> better-f3-jar. Внутри будет готовый .jar.
